LifeOS

The Chrome extension: add the page you're on, see what's due, and speak a note.

Connect

The address you open LifeOS at. Press Connect: a LifeOS tab opens (sign in there if it asks), you press one button, and the extension gets its own key. No copying.

Defaults

Separate tags with spaces. Leave empty for none.

Ways to add things

Toolbar button: add this page, check what's due, or record a voice note.

Right-click a page, some selected text, or a link: “Add … to LifeOS”.

Alt+Shift+A adds the current page instantly. Alt+Shift+V opens the voice recorder. (Change them at chrome://extensions/shortcuts.)

Address bar: type lf, press Tab, then a task to add it, or a few letters to find one.

Advanced

Only needed if Connect can't be used. Create a token in LifeOS → Settings → Connections → API.

Microphone

Chrome only shows the microphone prompt on a normal page, so allow it here once. The recorder then works for good.
